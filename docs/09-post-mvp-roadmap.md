# 09 — Post-MVP Roadmap

These systems are deliberately deferred.

## Map expansion

- larger rooms;
- multiple rooms;
- camera transitions;
- doors;
- purchasable areas.

## Barricades

- window boards;
- zombie destruction;
- player repair;
- repair rewards.

## Perks

Examples:
- Juggernog-like health perk.
- Speed Cola-like reload perk.
- Stamin-Up-like movement perk.
- Double Tap-like weapon modifier.

## Power

- power switch;
- powered interactions;
- powered areas.

## Pack-a-Punch

- upgraded weapon definitions;
- purchase flow;
- damage/ammo changes;
- visual/audio transformation.

## Combat expansion

- grenades;
- headshots;
- penetration;
- power-up drops;
- status effects.

## Enemy variety

- fast zombie;
- armored zombie;
- specials;
- bosses.

Only add navigation/pathfinding when world geometry actually requires it.

## Mystery Box expansion

- larger pool;
- weighted rarity;
- Teddy Bear;
- relocation points.

## Multiplayer

Treat multiplayer as a separate architecture project.

It would require decisions around:

- authoritative state;
- host/server model;
- zombie ownership;
- hitscan validation;
- economy/inventory synchronization;
- latency;
- reconnects.
