# Runtime-generated original sprite assets

The current playable graphics are generated by
`src/art/CharacterArt.ts`, `EnvironmentArt.ts`, and `HudArt.ts`.
The authoritative texture IDs and palette live in `ArtManifest.ts`.
This keeps 32×32 eight-direction character frames consistent across all
animation states without committing hundreds of tiny placeholder PNGs.

Future hand-authored PNG sprite sheets can be added under the individual
folders here. Do not add the approved concept screenshot as a gameplay
texture; the camera and 4-window collision layout must remain consistent.
